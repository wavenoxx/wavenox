## 2. Before vs. After Typography (`Inter Variable`)

- **Retained Stack:** Self-hosted `Inter Variable` (`/fonts/inter-latin-wght-normal.woff2` via `@fontsource-variable/inter`) with `tabular-nums`, medium weight (`500`) display/section headings, and `>= 12px` computed floor across the entire DOM.
- **Scale & Optical Tracking Refinement:**

| Role                                            | Before (`src/styles.css`)               | After (Workstream 2)                                                          |
| :---------------------------------------------- | :-------------------------------------- | :---------------------------------------------------------------------------- |
| Display (`--text-display` / `.text-display`)    | `clamp(36px, 4vw, 48px)`, `-0.015em`    | `clamp(2.125rem, 3.5vw + 1rem, 3rem)` (`34px–48px`), `-0.025em`, `lh 1.08`    |
| Headline (`--text-headline` / `.text-headline`) | `--text-title` (`28px–40px`), `-0.01em` | `clamp(1.625rem, 2.4vw + 0.9rem, 2.5rem)` (`26px–40px`), `-0.02em`, `lh 1.12` |
| Title (`--text-title` / `.text-title`)          | Shared with section headline            | `clamp(1.25rem, 1vw + 0.95rem, 1.5rem)` (`20px–24px`), `-0.015em`, `lh 1.25`  |
| Lead (`--text-lead` / `.text-body-lg`)          | `clamp(15px, 1.5vw, 17px)`, `lh 1.5`    | `clamp(0.9375rem, 0.45vw + 0.82rem, 1.0625rem)`, `-0.005em`, `lh 1.55`        |
| Body (`--text-body` / `.text-body`)             | `clamp(14px, 1.2vw, 15px)`, `lh 1.6`    | `clamp(0.875rem, 0.25vw + 0.8rem, 0.9375rem)`, `lh 1.6`                       |
| Stat Value (`--text-stat-value`)                | `clamp(24px, 2.5vw, 32px)`              | `clamp(1.1875rem, 2vw + 0.75rem, 2rem)` + `whitespace-nowrap tabular-nums`    |
| Eyebrow (`.text-eyebrow`)                       | Ad-hoc per component                    | `0.75rem` (`12px`), `500`, `tracking: 0.08em`, `uppercase`                    |
