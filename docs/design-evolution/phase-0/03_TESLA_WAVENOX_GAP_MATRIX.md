## 1. Priority Classification Definitions

- **`P0` — User-Blocking Design Defect:** Navigation unusable, text unreadable, major mobile overflow, inaccessible control, misleading conversion action, or broken interaction. _(Verified count in current WAVENOX baseline: **0** — all Step 8 release gates pass)._
- **`P1` — Major Experience Problem:** Confusing hierarchy, hero text/subject collision on mobile, competing CTAs, geographically inauthentic or duplicated imagery, double-preloaded hero assets, or excessive card density.
- **`P2` — Premium-Quality Improvement:** Spacing refinement, section consolidation, borderless editorial layout, MegaMenu link deduplication, and page rhythm optimization.
- **`P3` — Optional Polish:** Scroll-reveal micro-interaction tuning (`<Reveal>`), subtle hover transitions, and nonessential visual polish.
